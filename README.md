# Healthcare Lakehouse on Databricks

## Overview

This project demonstrates an end-to-end Healthcare Lakehouse built using Databricks Community Edition and Delta Lake.

## Technologies

- Databricks
- PySpark
- Spark SQL
- Delta Lake
- Python
- GitHub

- Silver Layer
- Gold Layer
